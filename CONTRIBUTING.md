# Contributing

Thanks for helping improve this list.

## Add a Tool

1. Confirm the tool has a useful free tier or open-source package.
2. Add it to the section where users would naturally compare it.
3. Use this format: `*   [Tool Name](https://example.com/) - Short practical description.`
4. Keep descriptions factual and focused on what the tool helps users do.
5. Open a pull request with the tool name and section in the title.

## Review Checklist

- The link is public and works.
- The entry is not a duplicate.
- The description does not include unsupported pricing or ranking claims.
- The tool is relevant to social media automation, content creation, research, or organization.
